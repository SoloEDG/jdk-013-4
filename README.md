# 潮汐之间

安装：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`；生产构建：`npm run build`。

路线逻辑测试：`npm run test:routes`（Node 内置 TS 剥离，无需额外依赖）。

Docker 启动：`docker compose up --build`，访问 http://localhost:8133 。

## 可分享路线（Routes）

「我的路线」把一次自由探索录制成可预览、可剪辑、可跨设备播放的路线，而不只是一组收藏。

### 录制

- 开始录制后，章节进度、镜头运动（按源媒体时间采样的关键帧）、热点打开、人物访谈进出都会成为路线步骤。
- 录制中可随时暂停/继续、回跳（seek）、重复访问同一人物；暂停等待不会进入主线时长。
- 支线访谈使用独立时钟，停留时间单独统计，永远不计入主线；每次支线返回都会在保存的返回点开启新的主线片段。
- 录制草稿实时写入 `localStorage`，刷新后可继续或放弃。

### 剪辑与重新衔接

- 可在主线片段内按源时间区间裁剪等待，或整段剪掉主线/支线；被剪片段以 `removed` 保留，可恢复。
- 裁剪后自动重铺路线时间轴，剪切点镜头由相邻关键帧插值得到（偏航走最短弧），其后的镜头与支线返回点重新衔接。
- 编辑器实时显示主线时长（不含支线）、支线停留、已剪时长与连续性自检结果。

### 导出 / 导入 / 跨设备容错

- 导出为单个 JSON（含素材版本快照），只包含有效步骤并重算时间轴。
- 接收端导入时做严格结构校验；素材版本不同、章节/人物/热点已下线时，受影响片段转为不占时长的 `gap` 步骤并给出解释，剩余路线完整保留、绝不清空。

### 引导播放与脱离

- 播放器按路线时间轴驱动章节媒体、镜头插值与支线段落切换。
- 接收者可随时「脱离路线」自由探索，界面显示将要接续的位置；「回到路线」从该接续点恢复。
- 播放进度条可在路线时间轴上任意拖动定位。

核心纯逻辑位于 `src/features/routes/lib/`（时间轴、裁剪、容错、序列化），不依赖 Vue/DOM，测试见 `tests/`。
